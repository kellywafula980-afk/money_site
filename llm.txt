# GLOBALGIGS - Job Board Platform

## About This File
This file helps AI assistants understand the GlobalGigs project context, architecture, and key decisions. It's designed for LLM context, not for debugging.

## Project Overview
GlobalGigs is a production-ready job board platform that aggregates remote job opportunities from multiple sources. It serves job seekers and employers with a modern, dark-themed interface.

### Mission
"Connecting talented professionals with global opportunities, eliminating barriers to remote work."

## Key Features for Job Seekers
- **Search & Filter**: Find jobs by keyword and category
- **Apply Free**: On-site applications with resume upload
- **No Degree Required**: Skills-based matching

## Key Features for Employers
- **Post Jobs**: Simple job posting with Paystack payment
- **Dashboard**: Manage listings and applications
- **Analytics**: Track views and applications

## Technical Architecture Summary
- **Framework**: Django 6.0.5 (Python 3.12)
- **Database**: PostgreSQL (production) / SQLite (development)
- **Frontend**: Tailwind CSS + Alpine.js
- **Hosting**: Render (free tier)
- **Payments**: Paystack integration
- **Scraping**: Multi-source aggregation with quality filtering

## Data Flow
1. Scraper collects jobs from RemoteOK and Himalayas
2. Quality filter removes spam (100+ char minimum, keyword blocking)
3. AI-powered categorization assigns one of 19 categories
4. Jobs are stored with enriched structured data
5. Users search, view, and apply
6. Employers manage listings via dashboard

## User Types
1. **Job Seekers**: Browse, search, and apply for jobs
2. **Employers**: Post jobs and manage applications
3. **Admins**: Manage content and users
